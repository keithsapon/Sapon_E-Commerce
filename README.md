# TAUshop — Static E-commerce Frontend

A responsive React + Vite e-commerce demo with separate customer and seller accounts.

## Demo accounts
- Customer: `user@example.com` / `user123`
- Seller: `seller@example.com` / `seller123`

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the project folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local address Vite prints (usually http://localhost:5173).

## Included
- Role-based login and validation
- Customer home, products, categories, cart, wishlist, orders, profile, logout
- Seller dashboard, product management (add/edit/delete), orders and seller profile
- Responsive desktop/tablet/mobile layout
- Cart and product management are simulated; seller catalog is saved in browser localStorage
- No backend, database, or real payment processing
